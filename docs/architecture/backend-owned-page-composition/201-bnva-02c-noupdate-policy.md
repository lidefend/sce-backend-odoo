# 201 · BNVA-02B-02C-02A · noupdate 策略

## 目标

- 不可变业务默认种子 → noupdate=1。
- 随产品版本演进的标准模板 → noupdate=1 + 显式受控迁移。
- 生成式基线 → noupdate=1 + 明确生成者与版本策略。
- 用户配置/覆盖 → 独立版本，永不受 XML 覆盖。
- 退役配置 → 保留历史，不自动恢复。

## 不做

- 不对 49 个文件一次性批量改 noupdate。
- 不把 noupdate=1 理解为永久冻结（它只是改变升级时数据重应用行为）。

## 实施门槛

02C-02B 先建立受控迁移机制，再按分类逐文件切换 noupdate=1。
