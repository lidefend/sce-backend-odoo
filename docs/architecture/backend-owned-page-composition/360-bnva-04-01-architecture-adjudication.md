# 360 · BNVA-04-01 Architecture Adjudication

## 结论

1. Odoo 标准模块被正确利用：标准模型被直接复用或 `_inherit` 扩展。
2. 平台内核（smart_core）与行业模块（smart_construction_core）职责分层清晰。
3. 未发现标准模型的平行 sc.* 复制；sc.* 是行业组合/汇总/工作流对象。
4. 17 个孤立候选不构成平行模型，是入口/生命周期治理问题。
5. 04-02 最小范围：187 个 sc.* 的逐项平行性复核 + 17 个孤立候选生命周期裁定。
6. 无需新增 ADR，可基于 L1–L4 原则形成后续决策。
