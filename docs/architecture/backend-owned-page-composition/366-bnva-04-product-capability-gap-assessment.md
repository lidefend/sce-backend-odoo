# 366 · BNVA-04 Product Capability Gap Assessment

## 已有完整产品能力（50 个 menu+contract）

付款执行、收款收入、结算单、采购申请、材料出入库、劳务申请/结算、设备申请/结算、分包申请/结算、
合同、报销、发票登记等已具备菜单 + 产品化契约。

## 缺口

- 69 个 workflow 有菜单但无 productized contract（页面契约待产品化）。
- 11 个 action-only 需确认调用方与业务角色。
- 17 个孤立 Action 需生命周期裁定（多数为 MERGE/RETIRE 候选）。

## 结论

“只有模型、没有入口”不成立；真实缺口是“有入口、无契约”的 69 个 workflow 与孤立动作清理。
