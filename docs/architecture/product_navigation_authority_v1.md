# 产品导航唯一权威（v1）

状态：锁定  
日期：2026-08-11

## 唯一运行链

```text
版本化产品发布策略
  ∩ Odoo 动作/模型/菜单组/ACL/记录规则事实
  → system.init.navigation_v1 + route_authority_v1
  → 前端纯渲染
```

## 不可变边界

- 产品页面是否发布、归属哪个中心、显示名称和结构顺序，只能由版本化产品策略决定。
- Odoo 继续拥有模型、视图、动作、权限组、ACL 和记录规则事实；不得重新成为产品导航选择器。
- 停用的原生菜单可以作为稳定 XMLID/权限组载体，但产品策略恢复不得修改其 `active` 状态。
- 没有原生菜单的正式页面以稳定动作 XMLID 投影；合成树节点 ID 不能冒充 Odoo `menu_id`。
- 配置工具属于同一产品面，必须进入产品发布策略，并在运行时通过角色权限裁剪；正式产品存在时禁止额外拼接原生配置菜单。
- `FinalMenuNavigationService`、菜单配置工作台和任何兼容 API 均不得静默回退原生菜单树。
- 前端不得决定业务页面是否发布、分组或授权，只能消费最终导航和路由权限契约。
