## 生效事实与消费链

| 事实 | 维护权威 | 消费者 |
| --- | --- | --- |
| 场景身份、名称、启停、顺序 | `sc.product.scenario`；code 为稳定身份，不随名称修改 | 导航投影、企业启用目录、工作空间、初始化诊断 |
| 入口归属与意图、顺序 | `sc.product.scenario.entry` | 导航投影、企业启用过滤、目录与工作空间 |
| 入口显式豁免 | `ir.ui.menu.sc_scenario_exempt` | 企业启用过滤；仍需发布及原生权限 |
| 企业启用状态 | 现有公司作用域 `business.v1:<scenario.code>`；原生参数优先、历史启用模型兼容读取 | 上述消费者沿同一场景 code 读取，不由文件反推归属 |
| 菜单/动作及中心归属 | 原生菜单、动作、父子关系及 `sc_product_center_id` | 菜单身份和中心展示；中心移动不改变所属场景 |

`load_runtime_surface` 与 `runtime_menu_scope` 是数据库事实的只读投影，不落另一份可编辑表，不在读取失败时退回 JSON。导航读取相同模型。场景归档保留绑定及身份，但不能通过企业启用控制。修改名称不改变启用身份；关联移动后立即按新场景检查。

企业启用参数与历史启用模型的兼容载体本批未迁移，也未声称其已统一为关系字段。后续如需改为关联模型，须迁移既有公司状态并处理优先级与删除生命周期；不能直接弃用现有参数导致启用状态丢失。

## 所有者最新裁定：三态授权

1. 有场景绑定：检查场景有效及当前公司启用；绑定不能与豁免并存，绑定操作清除旧豁免。
2. 无绑定且显式豁免：只跳过企业场景启用，发布、身份、公司、ACL、记录规则及执行时业务条件照常执行。
3. 无绑定且未豁免：配置缺失，拒绝交付与服务端入口授权，原因 `BUSINESS_SCENARIO_CONFIGURATION_MISSING`。

删除关联不再自动获得中心直连资格；中心直连只是展示形式。原报告中的旧行为作为历史源码事实保留，以上裁定取代其作为未来规则的效力。非执行菜单容器保留组织作用，不因此获得业务动作授权。裸 action 按其现有菜单入口检查；共享 action 仅在至少一个合法入口有效时保留。已有初始化内部动作的专用生命周期声明保留，不扩张它的作用域。

## 初始化与升级

模块版本升为 `17.0.0.175`，沿已有 `product_scenario_seed.xml` 标记场景作用域初始化完成。初始化不自动新增豁免，保留管理员已有的显式声明。

PR #812 复核修正：当前无关联、且不属于种子场景的菜单，也可能曾由管理员绑定后删除。数据库没有权威关联历史，无法据此证明“合法历史直连”；因此动作菜单、无动作叶子及种子外菜单均不按缺失推断豁免。已有合法直连入口若无明确声明，须由管理员核对后显式配置。再次升级不得补回删除的关联或被撤销的豁免；绑定再删除也不恢复绑定前的豁免。

此前候选的自动豁免实现未合入主线；若测试环境已执行旧实现，现有 true 值缺少来源信息，不能自动认定或批量撤销，须核对后明确维护。本次不重置已有数据库或冒充已完成旧候选数据修复。

回退不能只降级 Python：新增字段及 marker 保留，旧版本过滤链会恢复旧文件归属。回退前须评估已维护关联与企业启用差异，通过受管升级与重新验收实施；本批不自动部署或重置日常环境。
