# 往来款办理工作台 V1

日期：2026-08-11

## 产品边界

“往来款登记”是财务中心的办理编排入口，不是新的资金事实模型。工作台只收集项目、
往来对象、日期和说明，并由后端确定性分流：

- 项目借公司款、承包人借项目款进入 `sc.financing.loan`；
- 项目还公司款、承包人还项目款进入 `sc.expense.claim`；
- 账户间调拨进入 `sc.fund.account.operation`；
- 项目与对象资金往来由 `sc.finance.project.counterparty.position` 只读汇总和下钻。

前端只渲染后端契约，不判断业务类别、事实模型或会计影响。工作台不得保存业务金额、
审批状态、余额或台账事实。

## 权限与阻断

- 财务经办和财务管理能力可以进入工作台；其他角色不能绕过能力模型使用该入口。
- 缺少日期或说明仅提示，不阻断项目借还和账户调拨。
- 承包人借还款缺少往来对象会直接影响事实归属，因此属于操作一致性阻断。
- 完成、台账生成和余额影响继续由各事实模型既有权限与状态机负责。

## 发布判定

本能力达到 `RELEASED_FOUNDATION`：五种办理意图均绑定既有正式 action，业务分类代码、
项目和往来对象上下文由后端传递，统一台账可按项目和对象下钻。后续增强不得建立平行
往来款模型或在前端复制分流逻辑。
