# 公司与项目退款办理工作台 V1

日期：2026-08-12

## 产品边界

“公司&项目退款”是财务中心的退款编排入口，不是通用退款事实。后端按明确意图分流：

- 扣款实缴退回、投标保证金退回、合同保证金退回进入 `sc.expense.claim`；
- 自筹退回进入 `sc.self.funding.registration`；
- 资金和责任结果通过既有财务事实、责任事实、资金台账及项目对象往来投影查看。

工作台只收集项目、往来对象、日期和说明，不保存金额、账户、审批状态或余额。前端只
渲染后端契约，不解释退款类别，也不选择事实模型。

## 阻断规则

日期、说明和普通退款往来方缺失时仅提示完善。自筹退回会直接冲减公司与承包人的责任
余额，因此缺少往来对象属于运行一致性问题，必须阻断。其余审批、附件、账户和金额
校验由各正式单据模型负责。

## 发布判定

本能力达到 `RELEASED_FOUNDATION`。四种退款意图均绑定正式 action 和业务分类，财务
能力控制入口，项目与对象台账提供统一下钻。后续不得建立平行通用退款模型。
