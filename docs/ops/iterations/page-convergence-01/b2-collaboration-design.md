# PAGE-CONVERGENCE-01A · B2 责任矩阵与协作区域设计

## 业务关系分离（固定）

| 模块 | 业务表达 | 承载 |
| --- | --- | --- |
| 负责人 | 项目总体责任 | `user_id/manager_id/cost_manager_id/doc_manager_id`（责任信息组） |
| 责任矩阵 | 具体事项责任 | `responsibility_ids`（role_key/user_id/note） |
| 协作者 | 实际参与人员 | `collaborator_ids`（协作资料组） |
| 关注者 | 项目动态订阅 | chatter 关注者 |
| 附件 | 项目资料 | chatter 附件 |
| 评论 | 人员交流 | chatter 消息 |
| 活动 | 业务过程记录 | chatter 活动 |

不合并人员关系；不写死人数；不制造空态数据。

## 视觉层级

1. 责任信息：项目负责人用 avatar 突出，其余责任岗位同组排列。
2. 责任矩阵：责任岗位 / 责任人 / 说明三列，空态为「暂无可展示记录」。
3. 协作资料：项目标签与协作者分开展示，协作者与关注者不混排。
4. chatter：关注者独立订阅区；附件展示名称/类型/操作；评论与活动保持时间线。

## 实施边界

- 只通过受管视图配置与组件属性实现。
- 不修改人员关系数据、顺序、权限、数据来源和业务操作。
- 不新增渲染协议。
