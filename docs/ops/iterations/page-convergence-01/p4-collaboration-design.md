# PAGE-CONVERGENCE-01 / P4 · 项目协作区域设计

结论：协作区域已由现有原生字段 + 协作组件完整表达，本轮只做一处布局收敛，不建第二套协作系统。

## 一、关系边界（保持分离）

| 关系 | 字段/来源 | 业务含义 |
| --- | --- | --- |
| 协作者 | `collaborator_ids` | 参与项目工作的人员关系 |
| 关注者 | mail 关注者 | 订阅项目消息与动态 |
| 项目标签 | `tag_ids` | 项目分类标签 |

协作者与关注者不合并，人数动态读取，不写死，顺序与权限不变。

## 二、布局收敛（P4.1）

协作资料组由 `col="4"` 改为 `col="2"`：项目标签与协作者各占 1/2 宽度，数据填充后不拥挤；
责任矩阵保持 `col="1"` 整行。纯原生视图声明，无新增 CSS/Vue/协议。

## 三、附件 / 评论 / 活动（复用现有协作组件）

- 附件：资料名称、类型、时间、操作，随沟通与协作记录上传。
- 评论：交流内容、作者、时间。
- 活动：事件类型、发生时间、过程记录、待办。

三者由现有 mail 线程协作组件区分表达，未新增聊天或附件系统。
