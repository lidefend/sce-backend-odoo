# 劳务用工客户字段退出产品基线

## 决策

- 方单与零星用工统一使用 `sc.labor.usage`，以标准 `usage_type` 分类，不再依赖客户验收标签。
- 工种、施工部位、用工单价、用工金额和结算状态提升为产品标准字段。
- 用工金额按人数、工时和单价的标准口径计算；未填写工时时按一次计价处理。
- 两类入口分别绑定标准列表、标准域和默认业务类型。
- 历史可见字段、显示别名和客户来源投影退出产品基线。

## 隔离环境证据

- 项目：`sc-product-center-v1`
- 数据库：`sc_product_center`
- 升级前：客户遗留字段注册 `62`，物理列 `62`，业务记录 `0`。
- 升级后：客户遗留字段注册 `0`，物理列 `0`，业务记录 `0`。
- 正式动作审计：方单 13 列、零星用工 15 列，25 项总审计 `0` 失败。

## 安全边界

- `.121` 迁移对非空客户投影失败关闭。
- 未访问日常开发或生产数据库。
- 未删除、迁移或构造客户业务记录。
