# FEPC-13D 回归与实施准入计划

本文件是未来验收标准，全部新语义测试状态为 **not_run**。当前仅检查文档/JSON一致性，不将历史组件测试或CI作为新机制的验证结果。不得先实现后倒推契约。

## 准入

产品批准唯一方案、服务端声明负责人确认现有发布载体能表达精确occurrence绑定、协议负责人批准版本/能力/旧投影、前端负责人确认主身份与原生字段消费边界后，才另行授权实施。不得在本PR编辑正式schema、运行时配置或渲染器。

## 必须先建立的判别测试

| 层与现有入口候选 | 测试输入 | 必须观察的差异/结果 |
| --- | --- | --- |
| 服务端schema/声明编译单测（现有smart_core契约测试集） | 合法主身份+一个widgetRef；同字段另一个occurrence | 仅指定引用被关系绑定，无按fieldCode扩散 |
| 引用/权限负例 | 缺source、未知/重复ref、跨模型/嵌套关系ref、字段不匹配、未知policy、不可读字段 | 发布或交付显式拒绝；无兜底隐藏 |
| 版本交付测试（复用node_component_capabilities与契约交付测试体系） | capability×accepted version×structure version矩阵 | 旧客户端拿合法旧投影，新客户端拿新对象；缺能力不等于可静默送新key |
| 真实严格decoder（schema.ts对应既有测试） | 旧payload、新合法payload、未知key/enum/版本 | 旧不变、新能解码、非法拒绝；用真实旧decoder包验证降级，不只跑通用兼容分析 |
| presenter / bridge（canonical_form_presenter_test.ts现有入口） | global readonly但widget readonly=false；edit字段只读；create；主身份未就绪 | 复用最终readonly；仅合法readonly激活；编辑/创建及未就绪不省略 |
| 字段组件渲染测试（既有native renderer harness） | 名称+收藏+额外子节点、两处同字段、独立标题 | 只省略指定只读文本；原生区域、收藏及额外文本保留；未声明保持原样 |
| 页头模型/身份（既有product_page_header与page_identity入口） | source明确、旧subtitle不同、长名称、空值 | 新关系主身份唯一权威；旧链不受影响；无文本比较触发 |
| 增量/缓存测试 | 新旧能力交替、换角色/公司/record/view、patch和全量、撤回定义 | 无跨响应污染；不能留下被隐藏文本但页头已换记录 |

以上为复用入口方向，具体Make target与测试收集数量在实施任务中先解析并登记；不创建平行测试框架。不运行真实数据写入来证明UI事件，收藏/输入/保存事件用现有隔离组件或受管隔离fixture验证。

## 浏览器验收（复用现有标准页面入口）

在以后授权的冻结候选与隔离验收环境执行，不能在本轮Demo中点击写操作。

1. 查看态：真实生效关系及有效版本可回读；主身份视觉只出现一层；名称完整可读，长姓名/窄屏不截掉必要信息。记录语义h1、原生文本叶子、收藏、附加子节点和输入的DOM与坐标。不能只检查某个class存在。
2. 编辑态：显式读取effectiveRenderProfile，观察名称输入；输入事件与原descriptor相同，草稿/校验/保存/放弃/离开保护未变。若测试没有执行保存，不得称保存链已验证。
3. 创建态：无记录时保留名称输入与必填提示，不启用记录副本省略。
4. 收藏：只读禁用与授权可写两类用例；图标、aria-label、焦点和事件链保留，不把“按钮存在”等同于可用。业务写测试必须使用另行授权的隔离fixture及恢复/读回。
5. 固定页头：页面滚动、内部内容滚动及触发原生标题离开视口时，主要名称/返回/编辑入口继续可读可达；不得只验position:sticky文本。
6. 复合/独立标题及非项目表单：包括同字段多次出现、额外文字/子节点、没有新声明、没有原生标题。证明无误删/意外视觉变化。
7. 配置预览：原生字段定位不消失，能够观察关系声明但不应用省略策略。
8. 可访问：主身份可被屏幕阅读顺序识别；收藏accessible name不依赖已移除节点；不存在隐藏了唯一名称或焦点落在消失节点上的情况。

## 停止与发布条件

任一引用、权威、版本、模式或权限用例失败即停止后续UI验收；不得调默认值/放宽schema来保持绿色。截图、源码、契约、真实行为各自绑定候选与部署身份。实现PR通过并合并仍不代表Demo已部署。

回滚设计：撤回启用定义或停止向客户端交付该关系，恢复旧文本呈现；不迁移业务数据、不改变字段权限。发布协议必须保留可用旧版本协商及精确回退证据。F1、关注者、关系空状态、协作消息及Demo数据均不在回归修复范围。
