## 职责与根因

P0 通用前端呈现，目标为 ProfessionalFollowerManager 的样式。设计体系/通用组件负责视觉密度与响应式表现（backend_contract_boundaries.md 的设计体系职责），名单、顺序、计数、当前用户标记与动作权限继续消费现有输入。不引入新的产品参数、契约、排序或可见集合。

源码链：NativeCollaborationPanel → ProfessionalFollowerManager → ScList → TDesignList 的 `.t-list__inner` / `.t-list-item`。原 flex-wrap 加在外层 ScList 根节点，实际内层列表仍纵向排列；列表项同时保留标准纵向列表间距。历史 FEPC-09 记录19名真实关注者容器高914px，仅代表该样本。

产品差异仅 NativeCollaborationPanel.css：把换行和间距作用于关注者列表的内层节点，移除该列表项的纵向大间距；长姓名可换行、不截断；“我”标记不收缩；标题/动作行窄屏可换行。不修改 ScList 全局、组件脚本、业务数据、权限、时间线、项目标题或 F1。显式依赖当前 TDesign 列表内部类，升级组件库时须保留本次实际 DOM 回归。
