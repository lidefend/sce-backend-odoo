# 施工日志客户字段退出产品基线

## 决策

- `sc.construction.diary` 的标准模型已覆盖施工日志的完整业务办理信息。
- 正式列表与三套表单编排契约统一改用标准字段，不再通过客户验收展示别名呈现产品能力。
- 历史迁移锚点继续保留在模型内部，但从正式产品表单中移除。
- 升级前检测到任一非空 `legacy_visible_*` 字段即失败关闭。

## 隔离环境证据

- 项目：`sc-product-center-v1`
- 数据库：`sc_product_center`
- 升级前：注册客户字段 `62`，物理遗留列 `62`，业务记录 `0`。
- 升级后：注册客户字段 `0`，物理遗留列 `0`，业务记录 `0`。
- 未访问日常开发或生产环境。

## 保留边界

- 劳务、机械、租赁、薪资和结算仍存在产品办理字段与客户投影耦合，必须逐模型完成标准字段承接后再退出，禁止按空表直接强删。
