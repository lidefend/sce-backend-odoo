# 产品透传历史字段拆分（2026-08-11）

## 范围

本批只处理四个在混合兼容文件中“注册 62 个旧字段、但不参与产品页面计算”的模型：

- `sc.fund.account.operation`；
- `sc.receipt.income`；
- `sc.invoice.registration`；
- `construction.contract.expense`。

劳务、分包、机械、租赁、薪资、施工日志和结算单仍有历史字段参与计算或筛选，明确不在
本批批量删除范围内。

## 安全与验收

- 模块版本：`17.0.0.116`。
- 四表升级前逐表检查 62 个历史列；任一非空值触发
  `PASS_THROUGH_P2_HISTORY_NOT_EXTRACTED` 并中止整个升级。
- 隔离库升级前：四个模型记录数和历史非空数均为 0，旧注册字段及物理列各 62。
- 隔离库升级后：四个模型旧注册字段及物理列全部为 0，共清理 248 个空列。
- 迁移正反测试、行业产品边界、平台运行探针及 Schema：PASS，失败项 0。
- 未修改四个核心模型、正式视图、Action、权限或业务流程。
- 未访问日常开发或生产环境。

其他数据库必须先通过同一升级前检查；存在历史值时应由 P2 客户模块完成提取，禁止跳过
护栏直接清理 schema。
