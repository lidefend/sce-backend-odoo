# 人事薪资单 P2 字段剥离

## 目标

把项目管理人员工资登记从客户验收投影升级为可持续演进的产品办理能力，并完成当前产品模块最后一组客户字段清零。

## 产品基线

- 工资登记使用通用单据状态、项目、单号、业务日期、年度、月份、应发工资、实发工资、付款状态、已付款、未付款、备注、附件、录入人和录入时间。
- `paid_amount` 是可维护的实际付款金额；`payment_state` 与 `unpaid_amount` 由实发工资和已付款金额统一计算。
- 正式列表绑定标准树视图与标准表单，不再依赖只读客户验收字符串投影。
- 原人事、社保、补助和奖金办理能力保持在同一产品模型中，不另建客户专用模型。

## 数据安全与验收

- `17.0.0.123` 升级前置检查覆盖 62 个客户验收字段及薪资别名字段；存在非空历史值时失败关闭。
- 静态边界禁止重新引入客户验收模块，运行时边界要求模型字段和数据库列同时为零。
- 迁移负向测试、正式动作字段契约、发布策略探针和浏览器验收共同构成回归门禁。
- 验收仅使用隔离数据库 `sc_product_center`，不访问日常或生产数据库。
