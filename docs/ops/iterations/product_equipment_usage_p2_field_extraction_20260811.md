# 机械台班客户字段退出产品基线

## 决策

- `sc.equipment.usage` 继续作为机械台班的产品标准模型。
- 规格型号、计量单位、币种、台时单价和使用金额提升为标准业务字段。
- 使用金额按“使用台数 × 使用台时 × 台时单价”计算，避免列表投影保存独立金额口径。
- 正式列表和表单契约统一使用 `usage_date`、`usage_hours`、`recorder_id`、`create_date` 等原生字段。
- 曾用名、历史可见字段、来源录入人和客户验收菜单投影退出产品基线。

## 隔离环境证据

- 项目：`sc-product-center-v1`
- 数据库：`sc_product_center`
- 升级前：客户遗留字段注册 `62`，物理列 `62`，业务记录 `0`。
- 升级后：客户遗留字段注册 `0`，物理列 `0`，业务记录 `0`。
- 正式动作审计：机械台班绑定 16 个标准字段，25 项总审计 `0` 失败。

## 安全边界

- `.120` 迁移对非空客户投影失败关闭。
- 表单编排契约与正式列表契约同步切换到标准字段。
- 未访问日常开发或生产数据库。
- 未删除、迁移或构造客户业务记录。
