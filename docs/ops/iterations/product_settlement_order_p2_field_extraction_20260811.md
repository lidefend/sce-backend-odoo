# 合同结算客户字段退出产品基线

## 决策

- 收入与支出结算统一使用 `sc.settlement.order` 标准业务模型。
- 正式列表直接展示状态、项目、合同、结算单位、结算金额、付款金额、申请资金、可付余额、附件和录入人。
- 删除 `settlement_acceptance_*`、`user_acceptance_*` 和 `legacy_visible_*` 客户验收投影。
- 历史配置契约同步器将两套旧字段名归一到标准字段，避免升级后生成无效契约。

## 隔离环境证据

- 项目：`sc-product-center-v1`
- 数据库：`sc_product_center`
- 升级前：客户遗留字段注册 `62`，物理列 `62`，业务记录 `0`。
- 升级后：客户遗留字段注册 `0`，物理列 `0`，业务记录 `0`。
- 正式动作审计：收入/支出结算均绑定 17 个标准字段，25 项总审计 `0` 失败。

## 安全边界

- 非空历史字段由 `.119` 迁移守卫失败关闭。
- 未访问日常开发或生产数据库。
- 未删除、迁移或构造客户业务记录。
