# 材料租赁单 P2 字段剥离

## 目标

将材料租赁入场、退场办理所需的通用业务语义固化为产品字段，移除保留在产品模块中的客户验收投影字段，并保持既有业务数据安全边界。

## 产品基线

- 入场办理使用状态、单号、日期、供应商、使用单位、材料摘要、规格摘要、数量、含税金额、押金、备注、附件、负责人、创建时间和项目。
- 退场办理使用状态、项目、单号、实际退场日期、供应商、结算金额、赔偿费、维修费、运输费、附件、备注、负责人、创建时间、押金抵扣和使用单位。
- 结算金额由租赁金额与退场费用、押金抵扣统一计算；材料、规格和数量从明细行汇总。
- 产品运行模型、数据库物理列和正式动作不再依赖 `legacy_visible_*` 或客户别名字段。

## 数据安全与验收

- `17.0.0.122` 升级前置检查会扫描全部历史客户字段；只要存在非空历史值就失败关闭，禁止静默删除。
- 静态产品边界、运行时字段边界、正式动作字段契约和迁移负向测试共同阻止回退。
- 验收仅使用隔离数据库 `sc_product_center`，不访问日常或生产数据库。
