# ADR-003：甘特图时间轴 renderer（本期否决建设）

- 状态：Proposed（待批准；结论为**本期否决实施**，仅锁定候选方向与评估基准）
- 范围：custom-frontend-integration G5 / Gantt 专题
- 决策项：甘特库选型、自研与否、关键路径权威归属

## 背景

总控计划 §18 决策待办：「Gantt 工作日历、依赖类型和关键路径权威算法」。专题文档（gantt.md）已将其架构边界定为：时间轴 renderer 属 P0，施工任务、日历、依赖与写动作属 P1 后端权威；原型中「最终决策：自研 SVG」已 SUPERSEDED。

## 决策（建议）

**本期否决甘特建设**（P1 任务数据契约尚不存在，先建 renderer 即无事实可渲染），并锁定以下评估基准，供未来立项时引用：

1. **关键路径、自动排程、资源直方图等调度功能全部归后端权威算法**；前端甘特只做纯 renderer（任务条、依赖箭头、日历背景、缩放）。因此**任何甘特库的高级调度功能都不构成选型优势**——这直接改变评估权重。
2. **候选排序（未来立项时）**：
   - `frappe-gantt`（MIT，~30KB gzip，SVG 渲染，Frappe 公司维护）：功能极简恰好匹配「纯 renderer」定位；无官方 Vue 包装、无虚拟化（大数据量需自测）。
   - `dhtmlx-gantt` v10 社区版（MIT CE + PRO 商业分层，~300KB+）：注意专题文档中「商业授权」结论已过时——现行模式是 MIT 社区版（含任务条/依赖/手动排程）+ PRO 付费（自动排程/关键路径/资源）。因调度功能归后端，PRO 功能无采购必要；体积是主要否决因素。
   - 自研 SVG：仅当 frappe-gantt 在 500 任务数值预算或无障碍基线不达标时启动，且须单独立项。
3. **数值预算**：500 任务平移/缩放交互 <16ms 帧、首渲染 <500ms（冻结基线实测，不接受原型估算）。
4. **无障碍**：键盘导航 + ARIA 是硬门槛，frappe-gantt 现状需评估补齐成本。

## 事实核查（2026-09-03）

- frappe-gantt：MIT、零依赖、SVG、~6.1k stars、维护节奏平缓（社区修正偶发合入）。
- dhtmlx-gantt：npm v10.0.2 标注 MIT（社区版），~139K 月下载；完整版 ~300KB+ minified。
- vue-ganttastic：封装 dhtmlx，继承同一体积与 PRO 分层。
- 无任何候选库自带中文建筑日历（法定节假日/调休）——该能力无论如何都须后端下发日历事实。

## 回退策略

否决期内零代码、零依赖；未来立项时本 ADR 的评估基准可直接复用，不产生沉没成本。

## 后果

- G6/G7 甘特相关工作不排期；BOQ/进度数据契约设计时须预留 `calendar_ref`/`dependency` 语义位（仅契约占位，不实现）。
