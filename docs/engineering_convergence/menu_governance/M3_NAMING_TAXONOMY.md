# M3：正式命名词典与候选三级树

本文件是评审候选，不是 P1/P2/P3 产品事实。逐项资产仍在生成的 `menu_migration_mapping.csv` 中以 `investigate` 失败关闭；只有产品证据、运行时证据和兼容预检齐备后才允许填写正式路径。

## 命名词典

| 对象 | 推荐语法 | 禁止语法 | 裁决依据 |
| --- | --- | --- | --- |
| 一级业务域 | 2–6 字稳定业务名词 | 中心/后台/新版/角色名/动作名 | 回答“在哪个业务域工作” |
| 二级流程 | 业务子域或连续流程 | 多个无关对象拼接 | 回答“处理哪段流程” |
| 三级叶子 | 对象、单据、台账或明确报表 | 模型名、技术缩写、快速新建 | 回答“处理哪个对象或结果” |
| 工作台入口 | 我的任务、预警、常用入口 | 按业务域复制待办 | 个人任务聚合 |
| 台账 | 持续累积且可追溯记录 | 普通对象列表一律称台账 | 业务记录属性 |
| 报表/统计/分析 | 对象结果/聚合事实/解释洞察 | 按组件命名 | 展示目的 |

统一禁止：`legacy`、`runtime`、`projection`、`后台`、`（新）`、版本号、斜杠拼接和重复上级词。WBS 等保留缩写必须有统一中文名及帮助文本。

## 候选三级树框架

| 一级候选 | 二级候选 | 三级示例 | 当前状态 |
| --- | --- | --- | --- |
| 工作台 | 我的工作、预警提醒 | 我的待办、我的审批、我的项目 | 待角色频率证据 |
| 项目管理 | 项目立项、项目台账、项目策划、项目资料 | 立项申请、项目台账、工程结构、工程资料 | 待项目/生产边界裁决 |
| 经营管理 | 投标管理、合同管理、成本管理、结算管理 | 投标项目、收入合同、支出合同、项目预算 | 待合同/成本一级归属裁决 |
| 生产管理 | 施工、物资、分包、设备、质量安全 | 施工日志、进度计量、采购订单、质量检查 | 待真实角色任务证据 |
| 资金财务 | 收付款、发票税务、费用、资金账户、保证金 | 收款登记、付款申请、发票登记、报销申请 | 待财务角色证据 |
| 数据分析 | 经营、项目、成本、财务 | 项目经营分析、成本统计、资金分析 | 待指标权威映射 |
| 基础资料 | 组织人员、往来单位、业务字典 | 组织架构、客户、供应商、成本科目 | 待公司/项目上下文证据 |
| 系统管理 | 权限账号、流程、业务配置、运行审计 | 用户角色、流程定义、配置工作台、操作日志 | 仅管理员；恢复入口不可切断 |

## 逐项迁移规则

生成的映射表覆盖所有有效静态菜单 XML ID，并预留现状路径、候选三级路径、决定、产品证据、运行时证据及兼容策略。当前统一规则是：

- XML ID 与 action 在 M5 前保持不变。
- 没有产品与运行时证据时只能为 `investigate`。
- 超过三级优先转为页面内 tab、筛选、场景或项目上下文，不新增第四级。
- 动作型入口优先回归页面命令区或工作台，不能仅凭名称自动退休。
- 重复声明先识别加载顺序与兼容原因，禁止直接删除。

## 待决产品决策

| 决策 | 必需证据 | 决策人 | 当前状态 |
| --- | --- | --- | --- |
| 合同归经营管理还是独立一级 | 角色频率、跨项目/公司上下文、任务路径 | 产品负责人 | 未决 |

| 人事行政是否独立一级 | 正式产品范围、角色与使用频率 | 产品负责人 | 未决 |
| 工作台聚合哪些跨域任务 | 脱敏访问日志、待办来源与点击成本 | 产品负责人 | 未决 |

执行者不得自行关闭这些决策，也不得通过候选树反向修改 P1/P2/P3 权威载体。
